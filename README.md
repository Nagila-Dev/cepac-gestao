# CEPAC Gestão

Agenda de eventos culturais e equipes do CEPAC, em Barreiras e Luís Eduardo Magalhães.

Os dados ficam no navegador, em `localStorage`. Não há servidor.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço indicado pelo Vite, em geral `http://localhost:5173`.
